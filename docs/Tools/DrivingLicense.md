## 教学大纲
### 科目一：道路交通安全法律、法规和相关知识
+ 掌握法律、法规和规章中与道路交通安全有关的相关规定；
  + 机动车驾驶证申领、使用、管理
  + 驾驶行为
  + 交通违法行为及处罚
  + 机动车登记和使用
  + 交通事故处理
+ 了解机动车基本知识，掌握机动车主要仪表、指示灯和操纵装置、安全装置的基本知识。
  + 车辆结构常识
  + 车辆主要安全装置
  + 驾驶操纵装置的作用
  + 车辆性能
  + 车辆检查和维护
  + 车辆运行材料
  + 新能源汽车使用
+ 掌握道路交通信号的含义和作用；
+ 掌握各类道路条件下的通行规则；
+ 掌握地方性法规的重点内容；

### 科目二：基础和场地驾驶
+ 掌握基础驾驶和场地驾驶理论知识；
  + 基础驾驶操作理论知识
  + 驾驶姿势
  + 操纵装置的规范操作
  + 车辆安全检视
+ 掌握基础的驾驶操作要领，具备对车辆控制的基本能力；
+ 掌握基础操作和场内驾驶的基本方法，具备合理使用车辆操纵机件、正确控制车辆运动空间位置的能力，能够准确地控制车辆的行驶位置、速度和路线。
+ 倒车入库：库位宽度为`车宽+0.6m`，通常为[2.3m左右](https://www.youchejiuxing.com/lsj/6169.html)
  + 汽车前轮最大转角40度，前后轮轴距为2.7m时，后轮的转弯半径为`2.7m/tan(40度)=3.2m`
  + 当汽车后轮落在库位边线延长线上时，打死方向盘能够恰好倒入库回正并距边线30cm时，此时汽车后轮垂直线和道路边线角度应该为`arccos((3.2-0.3)/3.2)=25度`。当汽车角度和道路边线角度小于`180-25=155`度时，以左倒库为例，即使打满方向盘也会靠近右侧库位边线。

### 科目三：道路驾驶和安全文明驾驶常识
+ 道路驾驶
  + 掌握道路驾驶时的安全行车相关知识；
  + 掌握一般道路和夜间驾驶方法，能够根据不同的道路交通状况安全驾驶；
  + 具备自觉遵守交通法规、有效处置随机交通状况、无意识合理操纵车辆的能力，做到安全、文明、谨慎驾驶
+ 安全文明驾驶常识
  + 掌握各种道路条件、气象环境下的安全文明驾驶知识；
  + 掌握正确辨识各类道路交通信号的知识；
  + 掌握危险源辨识与防御性驾驶知识；
  + 掌握紧急情况下的临危处置知识；
  + 掌握发生交通事故后的现场处置方法；
  + 熟知伤员自救常识；
  + 了解常见危险化学品名称、特性等常识；正确分析各类典型事故案例。
