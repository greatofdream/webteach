# U 盘
[ChipGenius](https://www.52pojie.cn/thread-1349364-1-1.html)检测u盘的主控芯片和大小
+ 比如有一个u盘显示有14GB，使用ChipGenius，360U盘鉴别器均显示只有8GB，所以为扩容盘，超过某个体积就会立即报错。
```shell
　主控厂商: FirstChip(一芯)
　主控型号: FC212W
闪存识别码:　　98DE949376D1 - KIOXIA(铠侠) TC58TEG6DDLTA00 - 1CE/单通道 [MLC-16K] -> 总容量 = 8GB
```
+ 这个主控没有找到合适的量产工具，FirstChip的其它量产工具有[这里](https://www.52pojie.cn/thread-1537634-1-1.html)和[这里](https://www.upantool.com/liangchan/fristchip/14617.html)，官网可以下载[最新的工具](http://www.szfirstchip.com/col.jsp?id=137)
