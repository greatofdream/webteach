## Hanshuo价签
[2.3寸的经验贴](https://www.mydigit.cn/thread-236338-1-1.html) [反汇编查找指令的简略描述](https://www.mydigit.cn/thread-243908-1-1.html) [SSD1608的简述](https://www.mydigit.cn/thread-275704-1-1.html)，不过前面都没有详细描述流程。

4.2inch电子价签，型号Stellar-XL。[这里](https://www.mydigit.cn/thread-274369-1-1.html)有一个烧写的效果，。
+ 前后盖由卡扣连接，后盖扣在前盖的卡扣上，需要使用撬棒翘起一个缝，用铁片向外撬动后盖边缘，卡扣就脱落了。
+ 后盖上有4个纽扣电池，拆开后即和前盖上的电路板断开了连接
+ 排线上印着型号HINK-E042A13-A0，主控为SSD1619，无线模块为A7106，芯片为430G2553。
