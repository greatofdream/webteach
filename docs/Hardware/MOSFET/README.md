## 异或和同或门
+ YSYX提供了全定制的电路，需要注意P3和N3是有方向的，B连接在P3的源极，N3的源极
![](https://ysyx.oscc.cc/slides/2306/resources/img/tikz-images/d177bb7997ba32e4cef2b06bdf2f084745e0cc08.png)
+ 使用已有的门电路可以用公式表达异或门：
  + $A\oplus B=(!A\&B)|(A\&!B)$直接实现需要2个非门、两个与门和一个或门，共22个晶体管
  + 可以将上述表达式转化为与非与或非门，分别比与门和或门少2个晶体管$A\oplus B=\overline{\overline{(!A\&B)}\&(!A|B)}$，1个非门，2个与非，1个或门共16个晶体管。
  + 注意到上式中存在`!A`这一项，通过重新构造表达式 $A\oplus B=\overline{(A\&B)|(!A\&!B)}=\overline{(A\&B)|\overline{(A|B)}}$，1个与门，2个或非，共14个晶体管。
+ 同或门：$A\odot B=(A\&B)|(!A\&!B)=\overline{\overline{(A\&B)}\&(A|B)}$

## 编码器
+ 除了4-2编码器，还有特殊的编码如数码管，[编码逻辑](https://www.bilibili.com/opus/487457884494085563)，构造编码时可以每个数码段采用出现次数少的1或0作为表达式，降低电路连接复杂度。
+ 8-3编码器可以通过两个4-2编码器或组合输出`Y[1:0]`，高4位与输出`Y2`
+ 16-4编码器可以通过两个8-3编码器组合输出`Y[1:0]`，输入的高8位组合与输出`Y3`；通过4个4-2编码器组合输出低两位，输入的高8位组合与输出`Y3=and(X[15:8])`，输入的`and(X[:4])|and(X[15:12])`
+ 4-2优先编码器的`Y1`其实仍然是`A3|A2`，[我在视频的评论指出了](https://www.bilibili.com/video/BV1ZH4y1Q7Cv/?vd_source=da68eeb8cef88094046fa7a8e87d32e9)
+ 16-4优先编码器通过4个4-2优先编码器的输出`Z0[3:0]``Z1[3:0]`组合得到低两位，需要每个Z和高位先做与操作，确保高位均为0；Y3的逻辑和前文的16-4编码器一致；Y2较为复杂，`and(and(X[:4]),!and(X[15:8]))|and(X[15:12])`
+ 前导0计数可以通过优先编码器得到左边数字1的位置，进而得到；前导1的计数可以取反转换为前面情况。后缀计数看起来需要先倒排。

## 加法器
+ 加法器的进位和减法器的借位均可从低位传递给高位
+ 源码加法器的符号位
|A0|A1|S|C|
|-|-|-|-|
|0|0|0||
|1|1|1||
|0|1|1|减法借位1|
|0|1|0|减法无借位0|
|1|0|0|减法借位1|
|1|0|1|减法无借位0|
+ 反码加法可以转化为补码运算，变为全加器可以处理的情况，再转换回反码
+ 溢出只可能发生在正数相加和负数相加（同或），同时符号变化
+ 反码的设计导致存在两个0元，所以一定不是群，也无必要证明加法群同构；补码满足群定义，补码A为负数时，运算等效为`2^n-A`，所以一定与加法群同构

## 锁存器

+ D触发器是边沿触发

## 计算机系统的状态机模型
+ 处理器组成和工作原理。奇数相加的指令集与状态如下，其中由于r1初始化为1，所以最后每次先加r2，再更新r1，终止条件被设置为11.
|isa|machine code|PC r0 r1 r2 r3|
|-|-|-|
|||0 0 0 0 0|
|0: li r0, 11|10 00 1011|1 11 0 0 0|
|1: li r1, 1|10 01 0001|2 11 1 0 0|
|2: li r2, 0|10 10 0000||3 11 1 0 0|
|3: li r3, 2|10 11 0010||4 11 1 0 2|
|4: add r2, r2, r1|00 10 10 01|5 11 1 1 2|
|5: add r1, r1, r3|00 01 01 11|6 11 3 1 2|
|6: bner0 r1, 4|11 0100 01|4 11 3 1 2|
|...|...|...|
|7: bner0 r3, 7|11 0111 11|7 11 11 25 2|
+ 偶数相加的指令集与状态，由于可以先更新r1后更新r2，终止条件为10。
+ 指令集架构的状态机模型：GPR, PC, 存储器, 指令及其执行过程, 在计算机领域中属于指令集架构(Instruction Set Architecture, 缩写为ISA, 也简称指令集)的范畴
+ [Compiler Explorer](https://godbolt.org/)可以在线查看编译产生的汇编
+ 状态机联系
  + 根据ISA手册的功能描述, 画一张CPU的结构图 -> 处理器微结构设计
  + 根据结构图设计具体的电路 -> 逻辑设计
  + 开发程序 -> 软件编程
  + 将程序翻译成ISA手册中描述的指令序列 -> 编译
  + 在CPU上执行程序 = 用程序编译出的指令序列控制CPU电路进行状态转移
+ 简单处理器：表格整理了CPU的控制逻辑，比如只有add，li两种命令触发写，即置EN为1。
  + 新增指令`out rs`为读出数据，利用之前剩余的指令`01`和地址（此处为储存结果的r2）组合`01001000`，为了兼容之前的电路，特地将地址放在第4位

## 功能完备的迷你RISC-V处理器
+ RV32I
  + PC寄存器位宽：32；GPR共有32个， 每个GPR的位宽是32位，GPR0是固定值
  + 指令位宽是32位，四种核心指令格式 (R/I/S/U)
  + 在指令的基本格式中, 需要5位来表示一个GPR，因为一共有32个GPR
  + add指令的格式`rs2 rs1 rd op`
  + RV32E为嵌入式（Embedding）设备设计，寄存器数目从32减少到16
+ minirv: 支持如下8条指令: add, addi, lui, lw, lbu, sw, sb, jalr
  + 34章有机器码：0110011, 0010011, , , , , , 1100111
  + 寄存器即RAM，使用RAM宽度选择和指令宽度32一致，地址位宽理论上可以保持和PC寄存器一致`32=2^5`。
  + 测试程序中：a0=10,ra=1 
```shell
00000000 <_start>:
   0:	01400513          	addi	a0,zero,20 # R10=R10+20
   4:	010000e7          	jalr	ra,16(zero) # 10 <fun> # PC=0x10,R1=PC+4=8
   8:	00c000e7          	jalr	ra,12(zero) # c <halt> # PC=0xc, R1=PC+4=c

0000000c <halt>:
   c:	00c00067          	jalr	zero,12(zero) # c <halt> # PC=0xc, R0=PC+4无效

00000010 <fun>:
  10:	00a50513          	addi	a0,a0,10 # R10 = R10+10=30
  14:	00008067          	jalr	zero,0(ra) # PC=*(R1)=8
```
