# 行车记录仪

## 杰理
拆了一个2017年的行车记录仪，主控logo是pi的形状，在淘宝中识图查询是[杰理公司]()的芯片AC1649DAF-01A。芯片引脚有`32x4`个，但是官网上已经没有这款芯片的介绍。

+ [这里](http://bbs.yunthinker.com/forum.php?mod=viewthread&tid=15)提到了杰理丝印编号的规则，`-`前是生产批次，后面是产品编号，所以`AC1649DAF-01A`代表`ACxx01A`。
  + [这里](https://kagaimiq.github.io/jielie/chips/chip-marks.html)也提到了类似的规则，猜测我拆的这款芯片是`AC5x01A`
  + [芯查查](https://www.xcc.com/chip/brand/detail/8840)可以指定杰理搜索对应芯片，发现有一款`AC5701A`
  + [2021年的新闻](http://www.tome-sz.com/hynews_view.aspx?nid=1&typeid=50044&id=588)提到杰理在2017年有第一款芯片放在行车记录仪上的芯片`AC5201A`，而这款行车记录仪恰好是2017年的，虽然丝印上是2016年的芯片，但是大概率还是`AC5201A`
+ 行车记录仪开机后一段时间屏幕会变黑，无法显示任何东西。
