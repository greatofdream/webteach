# 字体
通常在包管理器中安装即可，如果没有包管理器权限，那么就需要手动拷贝对应的字体到需要的目录(`~/.fonts/`)来暂时解决字体问题。
## ctex
ctex 寻找字体的流程在`/usr/share/texmf-dist/tex/latex/ctex/fontset/ctex-fontset-ubuntu.def`中
+ AR PL KaitiM GB: [ttc](https://ctan.org/tex-archive/fonts/arphic-ttf?lang=en)
+ Noto Serif CJK SC: [ttc](https://github.com/notofonts/noto-cjk/tree/main/Serif/OTC)
